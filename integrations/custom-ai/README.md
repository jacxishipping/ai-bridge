# AI Bridge Custom AI Integration Guide

AI Bridge provides a universal API and SDK layer allowing developers, research teams, and enterprises to connect **their own AI models, custom LLMs, autonomous agents, and scripts** directly to any physical computer, workstation, VM, or server in their fleet.

---

## 🚀 Key Capabilities

- **Multi-Device Fleet Routing**: Direct commands, code execution, and desktop GUI actions to specific machines (`windows-pc`, `ubuntu`, `local`) by name or device ID.
- **Full Desktop GUI Automation**: Mouse clicks, cursor movement, scrolling, keystrokes, window focus, and display screenshots on Windows workstations.
- **Unrestricted Server Execution**: Run bash/sh, docker, systemd, and diagnostics on Linux servers.
- **Universal Tool Formats**: Native tool schemas exported on-demand in **OpenAI**, **Anthropic Claude**, **Google Gemini**, and standard JSON Schema.
- **OpenAI-Compatible `/v1/chat/completions`**: Point LangChain, CrewAI, AutoGen, Cursor, or the standard `openai` SDK directly to AI Bridge as a custom `base_url`.
- **Bring Your Own Key (BYOK)**: Supports OpenAI, Anthropic Claude, Gemini, Groq, DeepSeek, and local offline models via Ollama.
- **Python SDK (`ai_bridge.AIBridgeClient`)**: Clean, battery-included synchronous SDK.

## 🛠️ Methods to Connect Your AI

### 1. Python SDK (`AIBridgeClient`)
The fastest way to control devices from Python scripts:

```python
from ai_bridge import AIBridgeClient

# Initialize client
client = AIBridgeClient(
    base_url="https://jxiptvplayer.app",
    token="YOUR_ADMIN_OR_SESSION_TOKEN"
)

# 1. Discover online fleet devices
devices = client.list_devices()
print("Connected fleet:", [d["name"] for d in devices])

# 2. Run shell command on Linux server
result = client.run_shell("uptime", device="ubuntu")
print("Ubuntu uptime:", result)

# 3. Capture screenshot on Windows PC
shot = client.take_screenshot(device="windows-pc", quality=75)
print(f"Captured screen ({shot['width']}x{shot['height']})")

# 4. Control Windows Mouse & Keyboard
client.mouse_click(x=200, y=300, device="windows-pc")
client.keyboard_type("notepad.exe\n", device="windows-pc")
```

### 2. OpenAI Function Calling Agent
Empower GPT-4o with live computer control tools:

```python
import json
from openai import OpenAI
from ai_bridge import AIBridgeClient

bridge = AIBridgeClient(base_url="https://jxiptvplayer.app", token="YOUR_TOKEN")
openai = OpenAI(api_key="sk-...")

# Fetch 49 tools formatted for OpenAI function calling
tools = bridge.get_tools(format="openai")

# Run user prompt
messages = [{"role": "user", "content": "Check disk space on ubuntu and take a screenshot of windows-pc"}]

response = openai.chat.completions.create(
    model="gpt-4o",
    messages=messages,
    tools=tools
)

# Execute any tool calls generated by OpenAI
for call in response.choices[0].message.tool_calls or []:
    args = json.loads(call.function.arguments)
    dev = args.pop("device", None)
    res = bridge.execute(call.function.name, device=dev, args=args)
    print(f"Executed {call.function.name} on {dev}:", res)
```

### 3. Anthropic Claude 3.5 Sonnet Tool Use
Claude 3.5 Sonnet controls workstations and servers:

```python
from anthropic import Anthropic
from ai_bridge import AIBridgeClient

bridge = AIBridgeClient(base_url="https://jxiptvplayer.app", token="YOUR_TOKEN")
claude = Anthropic(api_key="sk-ant-...")

# Fetch tools in Anthropic schema
tools = bridge.get_tools(format="anthropic")

response = claude.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=4096,
    messages=[{"role": "user", "content": "List running docker containers on ubuntu"}],
    tools=tools
)
```

### 4. OpenAI-Compatible Chat Completions Proxy (`/v1/chat/completions`)
Point any OpenAI-compatible client, LangChain, or Cursor to AI Bridge:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://jxiptvplayer.app/v1",
    api_key="YOUR_AI_BRIDGE_TOKEN"
)

response = client.chat.completions.create(
    model="ai-bridge-agent",
    messages=[{"role": "user", "content": "Take a screenshot of windows-pc"}]
)

print(response.choices[0].message.content)
```

### 5. Direct REST API (cURL / HTTP)

#### Synchronous Tool Execution:
```bash
curl -X POST "https://jxiptvplayer.app/api/ai/execute" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "run_shell",
    "device": "ubuntu",
    "args": { "command": "uname -a" },
    "timeout": 30
  }'
```

#### Get Tools Catalog:
```bash
# OpenAI format
curl -s -H "Authorization: Bearer YOUR_TOKEN" "https://jxiptvplayer.app/api/ai/tools?format=openai"

# Anthropic format
curl -s -H "Authorization: Bearer YOUR_TOKEN" "https://jxiptvplayer.app/api/ai/tools?format=anthropic"
```

#### Fleet Capabilities:
```bash
curl -s -H "Authorization: Bearer YOUR_TOKEN" "https://jxiptvplayer.app/api/ai/devices"
```

## 🔒 Security & Policy Architecture

All tool invocations made by custom AI agents pass through AI Bridge's server-side policy engine:
- **Tier 1 (Read-Only)**: Instantly executed unattended (e.g. `get_system_info`, `list_processes`, `get_screen_size`).
- **Tier 2 (Low Risk)**: File creation, test runs within confinement.
- **Tier 3 (Sensitive / Desktop GUI)**: Shell execution, mouse/keyboard input, screenshots. Allowed unattended when configured or when targeting an unrestricted Linux server.
- **Tier 4 (High Risk)**: Irreversible deletions or privileged mutations require explicit approval via the dashboard or `/api/approvals`.
